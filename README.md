# 🏥 Healthcare Data Analysis

An end-to-end healthcare data analysis project built using Python, Pandas, Matplotlib, and Streamlit.

This project focuses on data wrangling, preprocessing, exploratory data analysis (EDA), visualization, and building an interactive dashboard for exploring healthcare data.

## 🚀 Live Demo

🔗 [Open the Healthcare Data Analysis Dashboard](https://healthcare-data-analysis-azfsbhbznyt2mhqpikgeoa.streamlit.app/)

## 📌 Project Overview

The goal of this project is to transform raw healthcare data into a clean and analysis-ready dataset and present meaningful insights through an interactive Streamlit application.

The project covers the complete data analysis workflow:

**Raw Data → Data Cleaning → Preprocessing → EDA → Visualization → Interactive Dashboard → Deployment**

## 🔍 Key Features

- Dataset overview and summary
- Data cleaning and preprocessing
- Duplicate and missing-value handling
- Data transformation
- Exploratory Data Analysis
- Interactive data visualizations
- Experiment-based analysis
- Cleaned dataset download
- Interactive Streamlit dashboard
- Cloud deployment

## 🧪 Experiments

The dashboard includes interactive experiments based on healthcare attributes such as:

- Billing Amount greater than 40,000
- Length of Stay greater than 10 days
- Age greater than or equal to 60 with high billing amount
- Length of Stay greater than 10 days with high billing amount

📊 Data Analysis Workflow
1. Data Loading

The healthcare dataset is loaded using Pandas.

2. Data Cleaning

The dataset is processed by handling duplicates, missing values, inconsistent values, and unnecessary columns.

3. Data Preprocessing

Relevant data transformations are performed to make the dataset suitable for analysis.

4. Exploratory Data Analysis

Different healthcare attributes are explored using statistical analysis and visualizations.

5. Interactive Dashboard

A Streamlit application was developed to allow users to explore the processed dataset and experiment with different conditions.

6. Deployment

The Streamlit application was deployed using Streamlit Community Cloud.
